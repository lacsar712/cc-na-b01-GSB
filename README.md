# 航标灯光巡检台

登记航标实测光强和方位偏差。保存前先向服务端要一份判定预览：预览给出即将写入的结论和说明，并下发一张短时预览凭证（默认 120 秒，可用环境变量 `PREVIEW_TOKEN_TTL_SECONDS` 调整）。真正写入必须带回这张凭证、勾选确认，且填写内容与申请预览时完全一致，否则表里行数不变。写入成功后，该行的凭证编号就是消耗掉的那张凭证。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

```bash
cd projects/11-nav-aid-inspection

```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 登记页填一条实测光强低于要求的记录，点“判定预览”：预览显示“不合格 · 光强不足”，并给出一张短时凭证编号。
3. 不拿凭证直接提交、拿到凭证但不勾选确认、或改动任一字段后用旧凭证提交，总表都仍是原来两行；等凭证过期再提交同样不落库。
4. 按预览原样勾选确认后写入，总表多出一行，新行和详情页都能看到消耗掉的凭证编号；同一张凭证不能重复写入。
5. 换 watch 登录，看不到登记入口；直接访问登记页、预览接口或提交登记都会被拒绝。
